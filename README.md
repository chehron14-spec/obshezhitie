# Система учёта заявок жильцов общежития

Проект команды 3 курса «Прикладная информатика» по дисциплине «Программная инженерия», осень 2026/2027.

## Проблема и пользователи
Жильцы сообщают о неисправностях устно или в чате — заявки теряются, нет прозрачности по срокам и ответственным.
Пользователи: жильцы, комендант (диспетчер), исполнители.

## Ключевые функции первого релиза
- подача заявки жильцом (категория, описание, фото, комната);
- кабинет диспетчера: назначение исполнителя и смена статуса;
- кабинет исполнителя: список назначенных заявок, отметка о выполнении;
- отслеживание статуса заявки жильцом;
- журнал заявок с фильтром по статусу, дате и категории.
